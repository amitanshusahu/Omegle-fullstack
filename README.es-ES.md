## 📌 Configurar el proyecto
- clona el repositorio y entra en él
```bash
git clone https://github.com/amitanshusahu/Omegle-fullstack/ & cd Omegle-fullstack/
```
- ve a la carpeta del cliente y ejecuta el servidor de desarrollo
```bash
cd client && npm run dev
```
- ve a la carpeta del servidor y ejecuta el servidor
```bash
cd ../server && npm start
```
